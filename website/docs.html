Getting Started

AI2Design is a free Figma plugin that reads a JSON schema and produces a fully editable ComponentSet (a component with multiple variants) directly on your current Figma page.

No Figma API knowledge is required. You write JSON that describes your component — its name, variant axes, and the visual tree of each variant — and the plugin handles the rest.

💡 AI2Design requires the Figma desktop app or Figma in the browser. It does not run in FigJam.

Quick start

  1. Install AI2Design from the Figma Community (search AI2Design).
  2. Open a Figma document and run the plugin from the Plugins menu.
  3. Choose a built-in example from the dropdown, or paste your own JSON.
  4. Click Apply Design. The component set appears centred in your viewport.

JSON Schema Overview

Every JSON payload must be a single object with type: "COMPONENT_SET" at the root. Here is the minimal shape:

JSON 
{
  "name": "Button",
  "type": "COMPONENT_SET",
  "description": "Optional description",
  "variantProperties": {
    "State": ["Default", "Hover"],
    "Size":  ["Sm", "Md", "Lg"]
  },
  "variants": [
    {
      "properties": { "State": "Default", "Size": "Sm" },
      "node": { "type": "FRAME", "children": [] }
    }
  ]
}
Field Type Required Description
name string Yes The name of the ComponentSet in Figma.
type "COMPONENT_SET" Yes Must be the literal string "COMPONENT_SET".
description string No Optional description attached to the ComponentSet.
variantProperties object Yes Declares the variant axes and their allowed values.
variants array Yes One entry per variant combination.

Node Types

Every node must have a type field. Nodes can be nested via children (on FRAME, and via wrapper frames for other types).

FRAME

The most common node type. Supports auto layout, padding, corner radius, and all base style fields.

Field Type Required Description
layoutMode "HORIZONTAL" | "VERTICAL" | "NONE" No Enables auto layout. Defaults to NONE.
primaryAxisAlignItems "MIN" | "CENTER" | "MAX" | "SPACE_BETWEEN" No Main axis alignment (requires layoutMode).
counterAxisAlignItems "MIN" | "CENTER" | "MAX" No Cross axis alignment (requires layoutMode).
layoutSizingHorizontal "FIXED" | "HUG" | "FILL" No Horizontal sizing behaviour. Requires layoutMode.
layoutSizingVertical "FIXED" | "HUG" | "FILL" No Vertical sizing behaviour. Requires layoutMode.
itemSpacing number * Gap between children. Required when layoutMode is set.
padding PaddingJSON * Inner padding. Required when layoutMode is set.
cornerRadius number No Uniform corner radius.
cornerRadiusIndividual CornerRadiusIndividual No Per-corner radii (topLeft, topRight, bottomRight, bottomLeft).
clipsContent boolean No Whether children are clipped to the frame bounds.
children NodeJSON[] No Nested child nodes.

TEXT

Field Type Required Description
characters string Yes The text content to display.
fontSize number No Font size in pixels.
fontWeight 100–900 No Numeric font weight (must be a multiple of 100).
fontFamily string No Font family name. Falls back to Inter if unavailable.
fontStyle "Regular" | "Medium" | "Bold" | "Italic" No Font style name.
textAlign "LEFT" | "CENTER" | "RIGHT" | "JUSTIFIED" No Horizontal text alignment.
textDecoration "NONE" | "UNDERLINE" | "STRIKETHROUGH" No Text decoration.
letterSpacing number No Letter spacing in pixels.
lineHeight LineHeightJSON No See Line Height below.

RECTANGLE

Supports all base style fields plus cornerRadius and cornerRadiusIndividual. Does not support auto layout. Children are placed in a transparent wrapper frame.

ELLIPSE

Supports all base style fields. No corner radius. Children are placed in a transparent wrapper frame.

Common fields (all node types)

Field Type Description
name string Layer name in Figma.
width number | "HUG" | "FILL" "HUG"/"FILL" only valid on FRAME with layoutMode set.
height number | "HUG" | "FILL" Same constraint as width.
opacity number (0–1) Layer opacity.
blendMode "NORMAL" | "MULTIPLY" | "SCREEN" | "OVERLAY" Layer blend mode.
fills PaintInput[] Fill paints. See Fills and Paints.
strokes PaintInput[] Stroke paints.
strokeWeight number Stroke thickness in pixels.
strokePosition "INSIDE" | "OUTSIDE" | "CENTER" Stroke alignment relative to the shape.
strokeDashes number[] Dash pattern for the stroke.
effects EffectJSON[] Layer effects. See Effects.
layoutSizingHorizontal "FIXED" | "HUG" | "FILL" Sizing on the horizontal axis inside an auto-layout parent. Valid on any node type. "FILL" stretches to fill the parent; "HUG" wraps content (FRAME only); "FIXED" keeps the explicit width.
layoutSizingVertical "FIXED" | "HUG" | "FILL" Sizing on the vertical axis inside an auto-layout parent. Same rules as layoutSizingHorizontal.

Variant Properties

variantProperties declares the axes of variation. Each key is a property name; the value is the array of allowed string values for that property.

JSON 
"variantProperties": {
  "State": ["Default", "Hover", "Pressed", "Disabled"],
  "Size":  ["Sm", "Md", "Lg"]
}

// Each variant entry must supply ALL property keys:
{
  "properties": { "State": "Default", "Size": "Sm" },
  "node": { ... }
}

Validation rules:

  • Every variant must include all keys defined in variantProperties.
  • No extra keys are allowed in variant properties.
  • Each value must be one of the declared allowed values for that key.
  • No two variants may share the same combination of property values.

Fills and Paints

Both fills and strokes accept an array of paint objects. Each item can be a hex string shorthand, a solid paint, a linear gradient, or a radial gradient.

Hex shorthand

JSON 
"fills": ["#D97757"]
"fills": ["#FFF"]          // 3-digit shorthand is expanded

Solid paint

JSON 
{ "type": "SOLID", "r": 0.49, "g": 0.35, "b": 0.97, "a": 1 }
// r, g, b, a must each be 0–1 (not 0–255)

Gradients

JSON 
// Linear gradient
{
  "type": "LINEAR_GRADIENT",
  "angle": 135,
  "stops": [
    { "r": 0.49, "g": 0.35, "b": 0.97, "position": 0 },
    { "r": 0.29, "g": 0.18, "b": 0.80, "position": 1 }
  ]
}

// Radial gradient
{
  "type": "RADIAL_GRADIENT",
  "stops": [
    { "r": 1, "g": 1, "b": 1, "a": 0.2, "position": 0 },
    { "r": 1, "g": 1, "b": 1, "a": 0,   "position": 1 }
  ]
}

Effects

type Required fields Optional
DROP_SHADOW color, offset (x, y), blur spread, visible
INNER_SHADOW color, offset (x, y), blur spread, visible
LAYER_BLUR radius visible
BACKGROUND_BLUR radius visible
JSON 
"effects": [
  {
    "type": "DROP_SHADOW",
    "color": { "r": 0, "g": 0, "b": 0, "a": 0.3 },
    "offset": { "x": 0, "y": 4 },
    "blur": 12,
    "spread": 0,
    "visible": true
  },
  {
    "type": "LAYER_BLUR",
    "radius": 8
  }
]

Layout and Sizing

Auto layout is enabled on a FRAME node by setting layoutMode to "HORIZONTAL" or "VERTICAL". When auto layout is active, itemSpacing and padding are required.

JSON 
{
  "type": "FRAME",
  "layoutMode": "HORIZONTAL",
  "primaryAxisAlignItems": "CENTER",
  "counterAxisAlignItems": "CENTER",
  "layoutSizingHorizontal": "HUG",
  "layoutSizingVertical": "HUG",
  "itemSpacing": 8,
  "padding": { "top": 12, "right": 16, "bottom": 12, "left": 16 },
  "children": [...]
}
💡 layoutSizingHorizontal and layoutSizingVertical work on any node type (FRAME, TEXT, RECTANGLE, ELLIPSE) when that node is a child of an auto-layout FRAME. Use "FILL" on a TEXT node to make it stretch to the parent width and wrap text. Use "FIXED" on a FRAME with an explicit width/height to prevent Figma from defaulting to HUG when layoutMode is set.

Typography

Font loading follows this priority: fontStyle → weight-derived style → "Regular". If the requested family is not available in Figma, it falls back to Inter Regular.

Field Type Notes
lineHeight.unit "PIXELS" | "PERCENT" | "AUTO" When unit is "AUTO", no value field is needed.
lineHeight.value number Required when unit is "PIXELS" or "PERCENT".
letterSpacing number Always interpreted as pixels.

Validation Rules

The schema is validated before any Figma nodes are created. All errors are reported together with dot-notation paths so you know exactly which field to fix.

Rule Error message
Root must be an object Root JSON must be an object
type must be COMPONENT_SET type must be "COMPONENT_SET"
name required name is required and must be a non-empty string
variantProperties required variantProperties is required and must be an object
At least one property variantProperties must declare at least one property
No duplicate variant combos variants[N].properties duplicates another variant combination
All variant keys present variants[N].properties is missing keys: …
No extra variant keys variants[N].properties has unexpected keys: …
Invalid fill hex fills[N] has invalid hex fill "…"
HUG/FILL on non-layout frame width/height "HUG" or "FILL" require layoutMode to be HORIZONTAL or VERTICAL
itemSpacing missing itemSpacing must be a number when layoutMode is HORIZONTAL or VERTICAL

Contributing

AI2Design is open source and welcomes contributions. Full contribution guidelines are in CONTRIBUTING.md.

Local setup

  1. Clone the repository and install dependencies: npm install
  2. Build the plugin: npm run build
  3. In Figma desktop, go to Plugins → Development → Import plugin from manifest and select manifest.json.
  4. For live rebuilds during development: npm run watch

Contributing to the website

The website lives in the website/ directory and is plain HTML, CSS, and ES modules — no build step required. Open website/index.html in a browser to start.

  • New page: Copy docs.html → new-page.html. Create corresponding CSS and JS files.
  • New feature card: Add a <div class="card"> in the features grid in index.html.
  • New docs section: Add a <section> with a unique id in docs.html. The sidebar ToC is auto-generated from heading IDs.
