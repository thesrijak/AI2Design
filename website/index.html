Features

Everything you need to build components

From simple rectangles to complex auto-layout frames with variant grids — all driven by a clean JSON schema.

Variant Component Sets

Define multiple variant axes (State, Size, Theme) and every combination is built as a real Figma component, automatically arranged in a grid.

Schema Validation

Every field is validated before anything is created. Get precise, path-aware error messages that tell you exactly what to fix.

Auto Layout

Full support for horizontal and vertical auto layout frames with configurable padding, spacing, alignment, and HUG/FILL sizing.

Fills & Gradients

Use hex shorthand, solid RGBA paints, linear gradients, or radial gradients on any node. Full opacity and blend mode control.

Typography

Set font family, weight, size, line height, letter spacing, alignment, and decoration. Falls back gracefully to Inter when a font is unavailable.

Effects & Strokes

Drop shadows, inner shadows, layer blur, background blur, configurable stroke weight and position — all available on every node type.

How it works

Three steps from schema to Figma

No Figma plugin API knowledge required. Write JSON, paste it in, and get production-ready components.

01
1

Write your JSON schema

Describe your component — its name, variant axes, and the visual structure of each variant using the AI2Design schema.

{ "name": "Button", "type": "COMPONENT_SET", "variantProperties": { "State": ["Default", "Hover"] } }
02
2

Paste it into the plugin

Open AI2Design in Figma, paste your JSON into the editor, and click Apply Design. The plugin validates the schema first.

// Or pick a built-in example: // Button, Card, Badge, // Input, Toggle, Custom
03
3

Get an editable component set

All variants are created as real Figma components, grouped into a component set, and centered in your viewport. Fully editable.

// ✓ State=Default // ✓ State=Hover // → Button (ComponentSet) // auto-positioned in grid
